# ÖZEL Trabzon Merkez Ağız ve Diş Sağlığı Polikliniği - Landing Page

Trabzon Ortahisar'daki özel diş polikliniği için hazırlanan mobil öncelikli, tek sayfalık modern landing page.

## Özellikler
- Mobil öncelikli (Mobile-First) duyarlı tasarım
- Tek dosya mimarisi (`index.html` içinde CSS & JS)
- Sabit mobil hızlı iletişim çubuğu (Hemen Ara & WhatsApp)
- Google Puanı (5.0) ve doğrulanmış hasta deneyimleri
- Tedaviler (İmplant, Kanal, Estetik, Pedodonti vb.)
- Sıkça Sorulan Sorular akordeonu
- Randevu talep formu ve KVKK modalı
- Schema.org (Dentist / LocalBusiness) JSON-LD SEO optimizasyonu
